# 日志管理与网络接入中间件学习指南

## 文档说明

本目录包含针对网络安全管理场景的日志管理和网络接入中间件的详细学习指南。

## 可用文档

### 主要指南
- **文件名**: `cybersecurity-logging-network-integration-guide.md`
- **适用对象**: 中文用户、国内网络安全从业者
- **内容**: 详细的日志中间件和网络接入工具学习路径

## 主要内容

### 1. 日志管理中间件
- ELK Stack (Elasticsearch, Logstash, Kibana)
- Apache Kafka
- Apache Flume
- SkyWalking
- Graylog
- Splunk

### 2. 网络接入中间件
- Syslog 协议支持
- SNMP 协议支持
- NetFlow/IPFIX
- Apache Camel
- Netty
- Apache NiFi

### 3. 学习路径
- 基础阶段 (2-3周)
- 中间件技术 (4-6周)
- 高级应用 (4-6周)
- 实战项目 (6-8周)

### 4. 安全性考虑
- 数据传输安全
- 访问控制
- 日志安全
- 合规性要求

### 5. 与Nacos集成
- 服务发现
- 配置管理
- 动态路由
- 多数据中心配置同步

## 使用场景

本指南特别适合以下场景：

- 政府、军方、上市公司等大型单位的安全管理
- 设备日志采集与分析
- 网络设备监控
- 安全事件管理 (SIEM)
- 脆弱性管理
- 合规性审计

- **编程语言**: Java
- **分布式框架**: Nacos, Spring Cloud

- **网络编程**: Netty
- **协议支持**: Syslog, SNMP, NetFlow/IPFIX
